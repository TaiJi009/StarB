# StarB

基于 AI Agent 的旅行地图标记 Web 应用。

## 产品定位

StarB 是一款围绕「地点 / 范围 / 路线」旅行的 AI 旅行地图应用。用户在地图上标记去过的地方，贴上感言、照片、视频、音频，形成个人旅行景点故事地图；AI Agent 可围绕指定地点/范围/路线搜集附近旅行信息（交通、旅店、餐饮等），并把规划过程沉淀为旅行故事的前置环节。

## 核心功能

- 空间视图：左侧地点列表 + 中央地图 + 右侧 AI TUI 面板
- 时间视图：旅程叙事流，时间线浏览，杂志画册风格，大幅照片，横向滚动
- 标记状态：想去 / 规划中 / 已去过
- AI 主动地图操作：打点、圈范围、画路线，AI 结果一键存为新标记
- 多用户在线，AI Agent 上下文严格隔离

## 技术栈

- 前端：React 18+ / TypeScript / Shadcn/ui + Tailwind CSS
- 后端：Python 3.11+ / FastAPI / PyCore
- 地图：CesiumJS（兼容高德/天地图坐标系）
- AI Agent：默认 DeepSeek，支持自定义模型提供商
- 附近旅行信息：地图服务商 API + LLM 联网搜索
